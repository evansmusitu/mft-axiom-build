## Release architecture

The Android APK is one carrier of the product, not the product itself. The same universal Chemistry core is built for Android and web/PWA delivery. The learning engine, FSRS implementation, native DEX files and core study state remain frozen from the repaired customer application. Frontier functionality is additive.

The universal layer contains MUSITU identity and commerce entitlement, Diagnose -> Revise -> Prove onboarding, cross-platform install guidance, offline behavior, Scientific Response OS, strict script CSP, responsive/accessibility hardening and server-authority separation.
