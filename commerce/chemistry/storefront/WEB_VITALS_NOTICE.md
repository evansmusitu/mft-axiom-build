# Vendored web-vitals

MUSITU self-hosts the pinned GoogleChrome `web-vitals` browser build so field measurement has no runtime CDN dependency.

- Package: `web-vitals`
- Version: `6.0.1`
- Upstream: https://github.com/GoogleChrome/web-vitals
- License: Apache-2.0
- Runtime use: Core Web Vitals measurement only; MUSITU does not use the attribution build.

The exact npm integrity, package shasum, tarball SHA-256, vendored-file SHA-256 and byte size are recorded in `WEB_VITALS_PROVENANCE.json`.
