# Parallel Distribution Workstream

This workstream must not modify the frozen OpenAI submission.

## Principle

One Axiom core; thin provider adapters; common capability registry; common governance/evidence; platform-specific packaging only.

## Workstream A — Claude / Anthropic

Goal:
- remote MCP connector submission;
- plugin bundle using MCP + selected Axiom skills where appropriate;
- separate evaluation of Claude Marketplace partner eligibility.

Requirements to validate before submission:
- provider-neutral OAuth redirect support;
- public tool profile;
- reviewer/demo account procedure;
- privacy/security metadata;
- current submission instructions.

Current public program signal:
https://claude.com/blog/build-plugins-for-claude

## Release gate before broad submission

Create and pass a universal distribution gate proving:
- canonical capability IDs;
- no semantic drift across providers;
- provider-neutral authentication with explicit redirect allowlists;
- MCP conformance;
- A2A conformance where required;
- common identity/entitlement/metering;
- evidence/provenance continuity;
- no mutation of OpenAI frozen surface;
- no weakening of external claim boundaries.

Distribution is a long-term acquisition machine. It runs in parallel with direct enterprise/OEM selling, which is the faster path to a $1M-class commitment.
