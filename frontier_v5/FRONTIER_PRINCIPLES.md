# MUSITU Axiom Frontier Principles

1. **Model agnostic:** foundation models are replaceable compute components, not the moat.
2. **Proof carrying:** material outputs include provenance, assumptions, transformations, verification and uncertainty.
3. **Fail closed:** missing data, invalid capability, failed verification or insufficient authorization blocks consequential execution.
4. **Progressive disclosure:** skill metadata stays compact; detailed references and deterministic scripts load only when needed.
5. **Composable specialists:** complex jobs recruit narrow expert skills through an orchestrator rather than one monolithic prompt.
6. **Longitudinal memory:** knowledge is temporal, provenance-aware, contradiction-aware and supersession-aware.
7. **Causal before narrative:** distinguish correlation, mechanism, intervention and counterfactual claims.
8. **Simulation before consequence:** high-impact recommendations are stress-tested against adverse and alternative worlds where practical.
9. **Instruction provenance:** untrusted retrieved content never acquires authority merely because an agent can read it.
10. **Continuous evaluation:** improvements are promoted only after attack, measurement, unseen evaluation and regression testing.
11. **Commercial value without trust erosion:** paid paths are surfaced only when genuinely relevant; no invented pricing, checkout, ROI or urgency.
12. **Public boundary preservation:** the OpenAI-facing surface never gains transaction or sensitive capabilities merely because the private core has them.
