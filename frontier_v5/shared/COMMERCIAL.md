# Commercial Conversion Contract

Revenue capture must follow demonstrated value.

Surface an account/paid/team/API/enterprise path only when:
- authentication is required for the requested protected computation;
- the user asks about plans, limits, billing, upgrading, API, teams, enterprise, or recurring usage;
- the requested workflow clearly requires a higher-volume/governed capability.

Rules:
- never invent a price, plan, discount, SLA, checkout URL, or ROI;
- never collect payment-card data in ChatGPT;
- never use false scarcity, urgency, or guaranteed-return language;
- keep purchase flows separate from quantitative conclusions;
- use only verified MUSITU-owned commercial URLs or account paths available from trusted current metadata.
