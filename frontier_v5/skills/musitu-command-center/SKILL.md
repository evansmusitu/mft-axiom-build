# musitu-command-center

## Operating contract
Use this skill as a composable MUSITU Axiom workflow. Do not assume a capability exists merely because this skill describes the workflow. Discover and use only tools exposed by the current runtime.

## Workflow
1. Clarify the decision and output contract.
2. Classify required evidence and missing inputs.
3. Discover MUSITU capabilities dynamically.
4. Select specialist workflows and dependency order.
5. Execute material quantitative work.
6. Run verification and contradiction checks.
7. Synthesize one decision-ready answer.
8. Surface paid/team/API access only when genuinely relevant.

## Mandatory quality gates
- Read `references/QUALITY.md` for evidence, calculation, safety, transaction, instruction-provenance, and claim rules.
- For a material or high-consequence result, read `references/PROOF.md`.
- For multi-skill work, follow `references/ROUTING.md`.
- Apply `references/COMMERCIAL.md` only when access/commercial intent is genuinely relevant.

## Completion
Do not finish with raw tool output. Return the requested decision, result, or artifact together with material assumptions, uncertainty, verification status, and unresolved blockers.
