# MUSITU Commercial Expansion
Read `../../shared/COMMERCIAL.md` and `../../shared/QUALITY.md`.

## Workflow
1. Identify the actual capability or outcome requested.
2. Determine whether authentication, volume, recurring use, team governance or API access is genuinely required.
3. Explain the access requirement without inventing a price or plan.
4. Use only verified current MUSITU commercial/account paths.
5. Never collect payment-card data or execute a financial transaction in ChatGPT.
6. Qualify enterprise needs: seats, frequency, sensitivity, governance, integrations and support.
7. Keep selling subordinate to successful user outcomes.
