# MUSITU Financial Modeling
Read `../../shared/QUALITY.md` and `../../shared/PROOF.md` for material models.

## Workflow
1. Normalize periods, currencies, units and signs.
2. Create an explicit assumption register.
3. Build calculations in dependency order.
4. Reconcile identities, cash flows and totals.
5. Run base, upside and downside cases.
6. Run sensitivity on the highest-impact drivers.
7. Identify break-even and value-destruction thresholds.
8. Return the model result with verification status and residual uncertainty.
