# MUSITU KPI & Metric Diagnostics
Read `../../shared/QUALITY.md`.

## Workflow
1. Define the metric and denominator exactly.
2. Trace source and transformation.
3. Check time, cohort and population alignment.
4. Decompose changes into drivers.
5. Test alternate definitions and denominator choices.
6. Identify measurement artifacts and broken comparability.
7. Link the metric to a concrete decision or control loop.
8. Return the canonical definition, diagnostic and caveats.
