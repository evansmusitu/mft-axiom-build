# MUSITU Market Sizing
Read `../../shared/QUALITY.md` and classify each input as evidence or assumption.

## Workflow
1. Define market boundary, geography and time horizon.
2. Inventory observable evidence and assumptions.
3. Build independent top-down and bottom-up estimates.
4. Triangulate discrepancies rather than averaging blindly.
5. Run sensitivity on adoption, pricing and population assumptions.
6. Avoid false precision.
7. State which new evidence would reduce uncertainty most.
8. Return a range, scenarios and decision implication.
