# MUSITU Optimization
Read `../../shared/QUALITY.md`.

## Workflow
1. Formalize objective, variables, bounds, constraints and units.
2. Check feasibility before solving.
3. Execute the appropriate exposed optimization capability.
4. Identify binding constraints.
5. Run sensitivity on scarce resources and limits.
6. Compare with a baseline or current policy.
7. Identify near-optimal alternatives and instability.
8. Return an implementable decision with feasibility status.
