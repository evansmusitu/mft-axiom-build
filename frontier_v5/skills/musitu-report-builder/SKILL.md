# MUSITU Report Builder
Read `../../shared/QUALITY.md` and preserve proof traceability for headline numbers.

## Workflow
1. Define audience, decision and output format.
2. Build an answer-first report spine.
3. Select only material evidence and calculations.
4. Use tables or visuals where they improve quantitative understanding.
5. Place assumptions and caveats adjacent to affected claims.
6. Make every headline number traceable.
7. Add technical/audit detail when needed.
8. Validate the finished report before handoff.
