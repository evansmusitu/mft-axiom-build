# MUSITU Scenario Factory
Read `../../shared/QUALITY.md`.

## Workflow
1. Define scenario variables, ranges and dependencies.
2. Separate shared assumptions from scenario-specific assumptions.
3. Generate scenarios without hidden assumption changes.
4. Execute comparable calculations consistently.
5. Identify nonlinearities, cliffs and breakpoints.
6. Rank drivers by outcome sensitivity.
7. Flag dominated, infeasible or internally inconsistent scenarios.
8. Return a scenario decision map with uncertainty.
