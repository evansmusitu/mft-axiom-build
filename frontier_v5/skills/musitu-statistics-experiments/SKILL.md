# MUSITU Statistics & Experiments
Read `../../shared/QUALITY.md`.

## Workflow
1. State the estimand or hypothesis.
2. Check study and data assumptions.
3. Select the exposed statistical operation.
4. Compute effect size and uncertainty.
5. Assess practical as well as statistical significance.
6. Apply multiplicity correction where required.
7. Run robustness checks.
8. Distinguish association from causation and return decision meaning.
