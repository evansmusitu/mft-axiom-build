# MUSITU Temporal Memory
Read `../../shared/QUALITY.md`.

## Workflow
1. Timestamp every material fact and assumption.
2. Record provenance and confidence.
3. Link superseding facts instead of erasing history.
4. Distinguish contradiction from legitimate temporal change.
5. Retrieve state as-of the requested date when needed.
6. Preserve unresolved conflicts and source disagreement.
7. Never convert unverified memory into authoritative evidence without revalidation when freshness matters.
