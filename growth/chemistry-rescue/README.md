# MUSITU Chemistry Rescue 2026 — National Launch Operating System

## Mission

Run a disciplined Zimbabwe-first growth program that helps A-Level Chemistry learners discover the free MUSITU Chemistry Rescue entry experience, then lets genuine product value drive sharing, teacher adoption, school interest and optional Premium intent.

Primary public entry:
`https://payments.mftintelligence.com/chemistry/rescue?src=direct`

This launch pack is an operating system, not evidence that production deployment or paid distribution has already occurred. Growth activity begins only after the exact Worker candidate passes product, commerce, privacy, accessibility, performance and deployment gates.

## Product and evidence boundary

- Free Rescue entry remains available without payment.
- Premium is optional and may unlock only after independently verified settlement and signed MUSITU entitlement issuance.
- Marketing must not invent grades, pass outcomes, user counts, school adoption, testimonials or endorsements.
- MUSITU must not imply affiliation with ZIMSEC, a school, a teacher or a public authority without real authorization.
- No scraped phone lists, unsolicited mass student messaging, fake social proof, bought followers or hidden referral identity.
- Acquisition measurement is aggregate-only and uses existing MUSITU privacy controls.

## Daily operating loop

1. Verify the public Rescue route and existing commerce/entitlement gates before publishing a new campaign push.
2. Publish useful Chemistry content first; attach one source-coded Rescue CTA.
3. Record only aggregate funnel evidence already permitted by the production telemetry contract.
4. Review source quality by downstream Rescue starts, shares and Premium intent—not reach alone.
5. Stop weak or misleading creatives rather than optimizing vanity metrics.
6. Escalate support/payment anomalies to the existing support and commerce evidence path; marketing must never override payment state.

## Decision metrics

The launch is judged on:
- Rescue visits by source class.
- Rescue starts by source class.
- learner-to-learner Rescue shares and peer starts.
- teacher/school/ambassador kit engagement.
- Premium intent and verified checkout progression.
- support friction.
- Core Web Vitals and existing field-experience health.

Views, likes and impressions are supporting diagnostics only.

## Launch sequence

`content QA → full repository preflight → exact Worker candidate seal → guarded production cutover → read-only live verification → controlled organic distribution → paid amplification only after funnel evidence`

No real-money settlement claim is added by this campaign. A paid-settlement claim requires separate verified settlement evidence.
