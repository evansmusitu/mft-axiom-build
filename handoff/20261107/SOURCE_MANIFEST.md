# Source inventory and restore instructions

The packaging GitHub Action generates these directories from a freshly fetched **public GitHub** repository:

- `PRODUCT/main/` from frozen canonical public main SHA.
- `PRODUCT/draft-76-phase210a/` from GitHub pull request #76 head `bd8adc82daf87c38a2d90894c6b297106eccb752`.
- `PRODUCT/draft-81-phase210b/` from GitHub pull request #81 head `5dd65a4a659730c4506cd5f350e29af793e5263e`.
- `PRODUCT/draft-87-evidence/` from GitHub pull request #87 head `23deaf0af81934bac311a94db12aebda98ce54ba`.
- `PRODUCT/draft-99-hyperdrive/` from GitHub pull request #99 head `a32fe6c53ec90aad8361e4b8056e6d23bc446f4a`.
- `SOURCE_HISTORY/public-github-all-refs.bundle` contains the Git history reachable from **all public GitHub branch and tag refs** at packaging time, including retained source branches (not just the five snapshots).
- `SOURCE_HISTORY/REFS.tsv` lists the exact bundled public refs and SHA values; `SOURCE_HISTORY/VERIFY.txt` stores bundle validation and counts.
- `HANDOFF/ARCHIVE_BUILD_LOG.txt` contains public packaging snapshot validation, date, and code revision pins. `HANDOFF/SHA256SUMS.txt` includes per-file SHA256 digests and is generated by the packager.

Git bundle inspection on a computer (optional):
```bash
git bundle verify SOURCE_HISTORY/public-github-all-refs.bundle
git bundle list-heads SOURCE_HISTORY/public-github-all-refs.bundle | head
git clone SOURCE_HISTORY/public-github-all-refs.bundle restored-public-history
```

**Important:** This bundle is the PUBLIC GitHub history only. The private, owner-authenticated GitLab mirror (180 branches and 1 tag) is NOT included because it is already preserved separately in a private GitHub archive. The private GitLab project's 23 historical issues / 35 merge requests and discussions were not copied by a Git mirror. Drive upload does not certify private historical privacy or external release readiness.

Production deployment configuration and source must remain pinned, tested and separately approved.
