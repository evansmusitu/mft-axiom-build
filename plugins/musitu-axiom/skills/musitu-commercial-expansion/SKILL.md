# MUSITU Existing Account Access

Read `references/COMMERCIAL.md` and `references/QUALITY.md`.

## Workflow
1. Identify the computation the user requested and the actual access error.
2. Discover the tools exposed by the current runtime.
3. Help reconnect the existing account through the secure OAuth flow when required.
4. Explain an entitlement or quota blocker plainly using verified current information.
5. Refer unresolved existing-account issues to the published official support contact.
6. Offer supported analytical work that is available under the existing entitlement.
7. Follow the public plugin commerce boundary: never display plans or prices, recommend upgrades, qualify sales leads, or initiate subscriptions, checkout, payments, trades, or transfers.
