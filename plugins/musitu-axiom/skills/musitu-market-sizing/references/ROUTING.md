# MUSITU Axiom Skill Routing

Use a command-center pattern:
1. Parse the user's desired outcome.
2. Identify required evidence.
3. Select the smallest set of specialist skills.
4. Resolve dependencies before execution.
5. Execute material computation through MUSITU Axiom when available.
6. Invoke verification before high-consequence completion.
7. Produce one integrated deliverable.

Prefer a specialist skill over a generic one when both match. Combine skills only when the task truly spans domains.
