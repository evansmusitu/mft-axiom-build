## Zero-spend preflight

Run `python read_only_host_gate.py` **only** from an owner-authenticated AWS CLI v2 session once account verification permits access. The CLI performs exactly four read-only API operations: Free Tier `GetAccountPlanState`, EC2 `DescribeInstanceTypes`, `DescribeImages` with `--owners amazon`, and `DescribeInstances`. It emits booleans only, never the account ID or credentials. It requires an active FREE plan, a positive future expiration, a USD $40 credit buffer, a real `t3.small` Free Tier eligible type with 2 GiB RAM, an official Windows Server 2022 English Full Base x64 AMI also labeled eligible, and no pre-existing EC2 instances in the pinned Stockholm region. Missing permissions/data fail closed. Tests use synthetic fixtures and cannot establish real AWS readiness.

**Passing the read-only checks only qualifies a manual infrastructure review.** It does not authorize `RunInstances`, creation of a security group, SSH/RDP exposure, IAM policy changes, a paid AWS upgrade or permanent hosting. Before any future launch, verify exact AMI and monthly Windows licensing/compute/EBS/public-IP costs from AWS; isolate the host; prove SSM Agent, minimum instance role permissions, outbound HTTPS and no public inbound RDP/MCP; protect all native keys on Windows; keep trade/compile/shell operations denied remotely; verify actual signed MT5/MetaEditor builds and owner-side localhost MCP. Check real broker history, live data freshness, terminal disconnects and restart policies separately. Maintain a hard stop at depleted credits/plan expiry. Never use GitHub Actions' transient Windows runner as 24/7 proof.
