# MUSITU Store V2 — isolated physical Android witness

This independent proof-of-installation Android application uses **com.musitu.store.v2acceptance** rather than production **com.musitu.store**. It is an offline technical probe only, not a replacement for the signed Store V1 and not the actual V2 multi-publisher installer.

It has no network, external-app-installation, payments, storage, camera, SMS or notification permission, no telemetry and no upload behavior. Debug signatures are generated by GitHub Actions for a disposable test; **never distribute as production-signed Store**.

## Safe phone test (user performs on their own Android)

1. Download the attached GitHub Actions ZIP artifact / private Drive ZIP and extract the *APK* from it. Verify the SHA-256 provided by CI against the APK using a trustworthy local hash viewer where possible.
2. Install only **MUSITU V2 Device Test** (package `com.musitu.store.v2acceptance`). If Android offers to *replace* production MUSITU Store, **cancel**: the package identity is wrong.
3. Open test app and confirm explicit orange "NOT MUSITU Store V2" label.
4. Tap **Copy receipt (manual, offline)**, then paste the receipt in your private ChatGPT conversation. Sharing is optional and includes only Android version, manufacturer/model, package/version, signer SHA-256 and timestamp. No device unique identifier.
5. Close/uninstall **MUSITU V2 Device Test** in normal Settings > Apps after verification, leaving production Store V1 unchanged.

CI proves source, permissions, signed APK and archive provenance. Only the user's real on-device action can prove physical installation/launch. This witness **does not certify** the actual Store V2 installer or real third-party APK installation. No third-party APK is bundled, no commerce or publisher enrollment is enabled.

## Local source

`gradle --no-daemon :app:assembleDebug` (with Android SDK 36 installed).
